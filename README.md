# Universal Code Review

A platform-independent, thorough workflow for reviewing coding changes before approval.

## Scope

This workflow can be used for:

- Frontend
- Backend
- Full-stack
- Database
- Testing
- Infrastructure
- Configuration
- Security-sensitive changes

## Internal modes

- Intake
- Full Review
- Re-review
- Audit

All modes use the same thorough review standard. The mode only changes the starting point and comparison context.

## Author

Created and maintained by Zayyan Rizka.

## Usage

Provide the AI with the repository, issue or ticket, pull request or branch, and any required access. The AI should produce a complete review report, manual testing instructions, and drafts for code-host and issue-tracker communication. External comments or decisions should only be sent after human confirmation.
